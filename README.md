# EyeBreak

最小的 macOS 菜单栏用眼提醒工具。无窗口、无 Dock 图标、无通知弹窗、无声音、无第三方依赖。

- 平时显示眼睛图标，每 20 分钟开始一次提醒。
- 菜单栏先以橙黄色背景显示 3、2、1，随后以绿色背景显示叶子图标和 20 秒休息倒计时；数字和图标为黑色。
- 两个倒计时阶段使用相同宽度的圆角色块，切换和数字变化时不会挤动相邻图标；平时及暂停时恢复无背景图标。
- 休息结束后重新开始 20 分钟计时。
- 点击菜单栏图标可查看剩余时间、立即休息、暂停／继续或退出。
- 菜单中的「开机自启」可切换登录 macOS 后自动启动，勾选状态以系统设置为准；添加此功能不会自动开启自启。若显示「待系统允许」，点击「在系统设置中允许…」完成设置，也可以再次点击开关取消待批准的注册。
- 系统或显示器睡眠时停止计时，唤醒后重新计时；手动暂停会保持。
- 平时使用一次性计时器等待下一次提醒；只有倒计时或菜单展开时才按秒更新。暂停及睡眠时取消计时器，静态图标复用。

## 构建和运行

需要 macOS 13 或更新版本和 Xcode Command Line Tools（或 Xcode）。

```sh
bash scripts/build.sh
open dist/EyeBreak.app
```

单独构建：`bash scripts/build.sh`。产物位于 `dist/EyeBreak.app`，可以直接双击启动，也可以拖到「应用程序」。重新构建前请退出已运行的版本。

构建使用本机 Swift 编译器，产物支持 macOS 13 及以上、面向当前 Mac 架构；不是经过公证的分发版本。

建议先将 App 放到「应用程序」等固定位置，再开启自启。若系统拒绝注册，菜单会显示具体错误。

## 手动验收

点击「立即休息」即可检查 3 秒准备和 20 秒休息的完整流程，无需等待 20 分钟。倒计时过程中可检查暂停／继续；菜单保持打开时倒计时也会继续。

开机自启可通过菜单开启／关闭，并在「系统设置 → 通用 → 登录项」中核对。外部修改后重新打开 App 菜单即可刷新状态；实际自动启动需在下次登录时确认。

提醒只发生在菜单栏内；菜单栏被自动隐藏时不会主动弹出。退出重启后重新计时，不保存进度。
